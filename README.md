# JD Phone Studio (Mac)

Stránka na Macu, cez ktorú vidíš a ovládaš svoje iPhony pripojené káblom.

1. Dvojklik na **NAVOD.html** – podrobný návod krok za krokom.
2. Raz spusti **install.command** (pravý klik → Otvoriť).
3. Odteraz vždy spúšťaj **START_STRANKY.command**.

Nové verzie sa inštalujú na stránke: Nastavenia → Aktualizácie.
